# 背景分页面紧凑布局设计

## 目标

带分页面背景图的普通页面应保留背景辨识度，同时确保文字清晰。多个模块以整齐的等宽等高网格排列，不因内容量不同出现高矮或胖瘦不一致；导航模块减少无意义空白。

## 设计

- 仅对带 `has-page-background` 的分页面启用视觉调整，普通页面和单模块沉浸模式保持现有行为。
- 页面背景覆盖层降低白色遮罩强度，让背景更清楚但不干扰内容阅读。
- 背景页的状态卡和模块卡使用统一半透明白色、轻微模糊、浅色边框与阴影，不要求逐个配置模块背景。
- 多模块网格使用拉伸对齐，同一网格行内卡片等高；固定列数仍保持等宽。
- 背景页导航卡片使用统一紧凑高度，条目超过可用空间时仅列表区域滚动，不把整张卡片无限拉长。
- 手机端使用单列统一紧凑高度，内容较多时在卡片内部滚动，保持整齐。

## 验证

- 自动测试确认背景类、柔化遮罩、等高网格和紧凑导航规则存在。
- 运行现有前端语法、TypeScript 与完整测试。
- 在真实浏览器检查桌面多列和手机单列布局。
