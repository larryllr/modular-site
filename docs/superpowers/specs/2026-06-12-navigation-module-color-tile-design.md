# 导航模块彩色磁贴设计

## 目标

在每个导航模块顶部增加一块整宽、鲜艳的长方形装饰磁贴，让多个导航模块更容易区分，同时保持标题和网址列表清晰。

## 视觉结构

- 磁贴位于导航模块内容最顶部、标题上方。
- 磁贴不显示图标、文字或网站数量，只承担装饰作用。
- 磁贴占满模块内容宽度，高度约 `34px`，使用与现有卡片一致的小圆角。
- 磁贴使用鲜艳的双颜色渐变和轻微彩色阴影。
- 标题继续单独显示在磁贴下方。
- 网址条目中的自动 favicon 保持不变。

## 配色

- 内置多组鲜艳渐变，例如紫蓝、粉橙、青绿和红紫。
- 根据导航模块 `id` 计算稳定色号，同一个模块每次加载保持相同配色。
- 不增加管理员配色字段，避免扩大配置结构和旧数据兼容范围。

## 响应式

- 单导航模块全屏模式和多模块卡片模式都显示磁贴。
- 手机端仍为整宽磁贴，高度略微缩小，避免占用过多阅读空间。

## 实现范围

- `public/app.js`：为导航模块计算稳定的配色类并渲染空装饰元素。
- `public/styles.css`：定义磁贴尺寸、渐变配色、阴影和手机端样式。
- 不修改 Worker 数据结构、管理员编辑表单或 Cloudflare KV 配置。

## 验证

- 源码断言确认导航模块包含装饰元素和稳定配色函数。
- 确认装饰元素没有文字内容。
- 执行 JavaScript 语法检查、TypeScript 检查和 `git diff --check`。
- 部署后记录 Cloudflare Version ID，并通过 `10808` 代理推送 GitHub。
