# 分页面模块单击三态设计

## 目标

分页面中的模块卡片支持三次单击循环：第一次在页面内展开，第二次进入全屏，第三次恢复原状。手机上下滑动、卡片内部滚动和控件操作不能误触状态切换。

## 适用范围

- 只作用于普通分页面的 `.page-module-grid > .module-card`。
- 不作用于主页入口、管理员预览、博客文章详情、底部独立评论区或自动单模块沉浸页。
- 页面刷新后所有模块恢复默认状态，不写入 KV 或本地存储。
- 同一时间最多有一个模块处于展开或全屏状态。

## 三态循环

1. 默认态：保留当前网格尺寸和等宽等高规则。
2. 展开态：模块跨满内容区整行，取消固定卡片高度，设置适合阅读的最小高度，内容按自身高度展开；其他模块仍保留并排列在下方。
3. 全屏态：模块固定覆盖整个视口，使用 `100dvh`，提高层级并允许模块内部滚动；页面底层停止滚动。
4. 全屏态再次单击后直接回到默认态，不经过展开态，并保持原页面滚动位置。

切换到另一张模块时，先恢复已有活动模块，再把新模块设为展开态。

## 手势判定

- 使用 Pointer Events，同时支持鼠标、触摸和触控笔。
- `pointerdown` 记录指针坐标、页面滚动位置和卡片滚动位置。
- 指针移动距离超过 `10px`、页面滚动位置改变或卡片自身发生滚动，即标记为滑动并取消本次切换。
- 只接受主按钮、单一主指针的完整按下/抬起序列。
- `pointercancel`、丢失指针捕获或在卡片外抬起都取消本次切换。
- 不阻止浏览器原生滚动，不在 `pointermove` 调用 `preventDefault()`。

## 控件豁免

当事件目标位于以下元素内时，不启动卡片状态切换：

- `a`、`button`、`input`、`textarea`、`select`、`option`
- `video`、`audio`
- `details`、`summary`
- `[contenteditable]`、`[role="button"]`、`[role="link"]`
- 管理按钮、表单、链接及其子元素

普通标题、说明文字、模块空白区域和非交互内容可以触发三态循环。

## 样式与可访问性

- 默认模块增加可点击光标和轻微状态过渡，但不改变现有卡片配色。
- 展开态使用 `grid-column: 1 / -1`，覆盖背景页现有的 `grid-column: auto !important` 规则，并取消背景页固定高度。
- 全屏态隐藏圆角和外阴影，保留模块内部样式；使用安全区内边距兼容手机刘海屏。
- 全屏时给根容器添加状态类以锁定页面滚动，退出时移除。
- 模块获得 `tabindex="0"` 和状态说明；`Enter`/空格执行同一循环，`Escape` 从展开或全屏直接恢复默认态。
- 使用 `aria-expanded` 表示默认态与活动态，并在全屏时增加 `aria-modal="true"`。

## 实现边界

- 前端新增独立的模块交互绑定函数，由 `renderPage()` 在模块插入网格后调用。
- 不修改模块数据结构、管理员配置、Worker API 或 KV。
- 不重新渲染整个页面；状态通过 DOM 类名切换，避免模块内部输入内容或播放状态丢失。

## 验证

- 自动测试覆盖默认→展开→全屏→默认循环、同一时间单活动模块、控件豁免、`10px` 滑动阈值、页面/卡片滚动取消和 `Escape` 恢复。
- 验证背景页固定高度规则不会覆盖展开态和全屏态。
- 在桌面和 `390×844` 手机视口真实测试：点击标题区域循环三态，拖动页面和卡片内部列表不会误触，按钮、输入框、链接和视频仍按原功能工作。
