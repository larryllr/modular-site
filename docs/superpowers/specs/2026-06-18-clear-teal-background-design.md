# 清晰青色背景设计

## 目标

按用户重新确认的视觉稿，让带背景图分页面直接展示清晰海景，而不是覆盖灰白雾层。背景负责营造氛围，白色半透明卡片负责承载内容，现有整齐网格与全部交互保持不变。

## 视觉处理

- 背景图与内容层分离，保留图像清晰度，仅轻微降低亮度、提高青色氛围，不使用模糊。
- 页面叠加从左上深青到右下透明的方向性渐变，让标题区域具有足够对比，同时保留右侧水面高光。
- 背景页标题、路径和说明改为白色系，标题分隔线使用低透明白色。
- 状态卡和模块卡使用约 90% 不透明的白色表面、细白边框、轻微冷色阴影和很小的背景模糊。
- 页面侧边栏、按钮、图标、模块内容、网格列数与现有等宽等高尺寸保持不变。
- 单模块沉浸页继续使用现有全屏行为。

## 实现边界

- 只调整 `applyPageBackground()` 输出的背景变量和 `has-page-background` 相关 CSS。
- 不增加管理员配置项，不迁移背景数据，不修改 Worker 或 KV 数据结构。
- 管理员预览继续显示同方向的青色背景处理。

## 验证

- 自动测试确认独立背景层、深青方向渐变、白色标题和半透明卡片规则存在。
- 在正式 `/guide` 相同桌面与手机视口截图，将用户确认的视觉稿和真实实现并排检查背景清晰度、标题对比度、卡片融合和网格尺寸。
