# `/llr-mariorun` 老师大冒险设计

## 目标

上线一个马里奥风格的横版跳跃小游戏，路径为 `/llr-mariorun`。玩家开始前选择素材包和关卡；完整管理员可以在线编辑素材包和关卡。游戏默认提供 10 个原创长关卡，每关目标游玩时长约 5 分钟；关卡节奏参考经典平台跳跃游戏，但不内置或复制 Nintendo 原版关卡地图数据、素材、音乐或角色。

## 版权与内容边界

- 不使用 Super Mario、Mario、Nintendo 原始素材、音乐、角色名或原版关卡坐标。
- 默认关卡是原创布局，只借鉴横版平台跳跃的通用节奏：平地、问号块、蘑菇、管道、坑、敌人、旗杆、城堡、Boss、公主/救出目标。
- 管理员编辑器允许用户自行创建、导入、导出和修改关卡；系统不内置原版关卡数据。
- 页面和入口默认命名为“老师大冒险”，URL 固定为 `/llr-mariorun`。

## 用户体验

### 前台开始流程

1. 访问 `/llr-mariorun`。
2. 显示标题、键位说明和素材包选择区。
3. 玩家选择素材包。
4. 玩家选择关卡。
5. 点击“开始游戏”进入横版游戏。
6. 游戏中可暂停、重开当前关卡、返回选择界面。

### 桌面键位

开始界面必须显示键位提示：

- 方向键或 `A`/`D`：左右移动。
- 空格、`W` 或 `↑`：跳跃。
- `Shift` 或 `J`：加速/攻击。
- `S` 或 `↓`：下蹲/进管道。
- `Esc`：暂停。
- `R`：重开当前关卡。

### 手机端

游戏逻辑永远以横屏坐标运行。

- 优先尝试浏览器横屏锁定。
- 如果浏览器不支持或拒绝横屏锁定，启用“竖屏内横屏模式”：游戏容器在竖屏页面内旋转 90 度并缩放到可完整显示。
- 虚拟按键跟随横屏游戏方向摆放。
- 左侧：左、右、下。
- 右侧：跳跃、加速/攻击。
- 支持多点触控，例如按住右键同时跳跃。
- 竖屏兼容模式显示轻提示：“当前为兼容横屏模式，横拿手机体验更好。”但不阻止游玩。

## 游戏运行时

第一版使用项目内自研 Canvas 2D 运行时，不直接集成 FullScreenMario 原始代码。这样可以避免版权和体积问题，也更容易把素材包、关卡编辑器、手机虚拟按键和后台接口整合到现有站点。

### 模块边界

- `public/llr-mariorun/index.html`：游戏页面壳。
- `public/llr-mariorun/game.js`：游戏启动、菜单、输入、主循环、关卡加载。
- `public/llr-mariorun/game.css`：横屏布局、竖屏旋转模式、虚拟按键、菜单。
- Worker API：素材包、关卡、R2 素材上传、素材读取。
- `public/app.js`：管理员后台增加素材包和关卡编辑入口，主页/侧边栏增加游戏入口。

### 运行时能力

- Canvas 2D 横版平台跳跃。
- 玩家移动、跳跃、重力、碰撞、踩怪、受伤、通关。
- 关卡摄像机横向跟随。
- 地形、金币、道具、敌人、陷阱、Boss、救出目标。
- 素材缺失时使用内置 SVG/Data URL 占位图，游戏不崩溃。
- 关卡失败后从最近检查点重生。

- 上传时生成安全 R2 key，不使用原始文件名作为公开路径。
- 图片在前端上传前尽量压缩，后台仍校验 MIME 和大小。

## R2 与 KV 存储

新增 R2 bucket：

- bucket 名称：`llr-mariorun-assets`
- Worker binding：`GAME_ASSETS`

KV 保存结构化元数据：

- `game:asset-packs`：素材包列表和每个槽位的 R2 key、contentType、size、updatedAt。
- `game:levels`：关卡列表和地图 JSON。

R2 保存二进制素材文件。前台不直接访问公开 bucket，而是通过 Worker 路由读取：

- `GET /api/game/assets/:key`

这样不需要开启 R2 public bucket，也不需要单独配置 CORS。

## API

### 公开 API

- `GET /api/game/manifest`
  - 返回启用素材包列表、启用关卡列表、默认素材包 ID、默认关卡 ID、素材槽位清单。
- `GET /api/game/assets/:key`
  - 从 R2 返回素材文件，带 `content-type`、长期缓存和安全 key 校验。

### 管理 API

完整管理员 token required：

- `GET /api/admin/game`
  - 返回所有素材包和所有关卡。
- `PUT /api/admin/game/asset-packs`
  - 保存素材包元数据。
- `POST /api/admin/game/assets`
  - 上传单个素材文件到 R2，返回 object key 和 URL。
- `DELETE /api/admin/game/assets/:key`
  - 删除 R2 素材。
- `PUT /api/admin/game/levels`
  - 保存关卡列表和地图 JSON。

所有管理 API 使用现有 Bearer token 机制；limited 管理员返回 403。

## 默认 10 个原创长关卡

每关目标时长约 5 分钟，包含 4 到 6 个段落，至少 2 个检查点。第一版关卡数据可以先用结构化 JSON 表达，后续管理员可在线继续改。

1. **新手草地长路**
   - 开场安全平地。
   - 问号块和第一个蘑菇。
   - 两段普通怪教学。
   - 管道上层金币路线。
   - 小坑和旗杆终点。
2. **管道丘陵**
   - 高低管道组合。
   - 食人花教学。
   - 管道间金币路线。
   - 隐藏奖励砖块。
   - 连续小坑和旗杆。
3. **地下金币矿洞**
   - 地下背景。
   - 砖块密集走廊。
   - 金币房。
   - 乌龟怪首次出现。
   - 管道返回地面终点。
4. **高空平台群岛**
   - 悬空平台。
   - 金币提示跳跃轨迹。
   - 掉落后进入低层绕路，不立即死亡。
   - 飞行怪。
   - 高台旗杆。
5. **森林怪物巡逻线**
   - 森林背景。
   - 普通怪、乌龟怪、食人花组合。
   - 中段补给点。
   - 可顶砖块通道。
   - 终点前小怪群。
6. **蘑菇弹跳峡谷**
   - 弹跳蘑菇平台。
   - 空中金币路线。
   - 移动平台。
   - 上方隐藏奖励区。
   - 低层回收路线。
7. **冰面滑行工厂**
   - 低摩擦冰面。
   - 长平路加小坑。
   - 踢壳清怪路线。
   - 星星爽快段。
   - 终点前刹车考验。
8. **黑夜管道迷宫**
   - 黑夜与地下混合背景。
   - 多管道入口。
   - 错误管道只绕路，不重罚。
   - 金币提示正确路线。
   - 隐藏金币房。
9. **城堡火焰桥**
   - 城堡背景。
   - 岩浆坑。
   - 火球机关。
   - 移动平台。
   - Boss 小兵。
   - 城堡门终点。
10. **Boss 与公主终章**
    - 短城堡前半段。
    - 补给蘑菇。
    - Boss 战房间。
    - Boss 3 点生命。
    - 打败 Boss 后门打开。
    - 救出目标与胜利画面。
