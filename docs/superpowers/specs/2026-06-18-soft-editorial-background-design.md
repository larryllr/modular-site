# 柔焦浅色背景设计

## 目标

修复带背景图分页面目前灰白、发脏、背景与白卡片割裂的问题。采用用户选择的“方案 2：柔焦浅色”，让背景保留场景感但退居内容之后，同时维持现有整齐网格和全部交互。

## 视觉处理

- 背景图与内容层分离，背景图使用轻微模糊、降低饱和度和很小幅度提亮，不再把高透明白色直接烘焙进 `background-image`。
- 页面使用暖白色纵向渐变遮罩：标题区域更实，向页面下方逐渐变透明，让背景自然露出。
- 状态卡和模块卡使用约 92% 不透明的暖白表面，取消厚重投影，改为细冷灰边框和极轻阴影。
- 页面标题、侧边栏、按钮、图标、模块内容、网格列数与现有等宽等高尺寸保持不变。
- 单模块沉浸页继续使用现有全屏行为，不加入多模块页面的卡片处理。

## 实现边界

- 只调整 `applyPageBackground()` 输出的背景变量和 `has-page-background` 相关 CSS。
- 不增加管理员配置项，不迁移现有背景数据，不修改 Worker 或 KV 数据结构。
- 浏览器不支持 `filter` 或 `backdrop-filter` 时仍显示清晰暖白卡片和可读背景。

## 验证

- 自动测试确认背景图改为独立伪元素、暖白渐变遮罩、卡片表面和单模块兼容规则存在。
- 在正式 `/guide` 相同桌面视口和手机视口截图，和用户原截图并排检查背景色调、卡片融合、文字对比度与网格尺寸。
